# sbti

[sbti online](https://sbti-test.online)

什么是 SBTI
一个更偏中文互联网语境、以情境反应和关系模式为核心的娱乐向人格测试。

SBTI 测试的核心特点
SBTI 不像传统量表那样堆很多抽象术语，它更喜欢把问题放进具体场景里，比如关系中的不安、面对他人评价时的反应、做决定时的犹豫或推进欲。

所以它测出来的更像是一个“你平时是怎么活着、怎么想人、怎么处理关系”的人格画像，而不是医学意义上的诊断标签。

SBTI 是怎么测的
进入首页后直接答题，不需要额外跳转。
每道题会被归入 15 个维度之一，例如自我模型、情感模型、态度模型、行动驱力模型、社交模型。
系统会根据每个维度的得分，把你映射到不同人格模式，并输出最终结果。
做完测试后能看到什么
你的人格名称与对应简称代码。
完整的人格文案介绍，包括这个人格在关系、行动和世界观上的典型表现。
15 个维度的命中解释，帮助你知道自己为什么会落到这个结果上。

举例：
